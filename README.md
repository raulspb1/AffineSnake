# AffineSnake — Финальная работа («C++ для робототехников»)

Модификация классической игры «Змейка» на C++ и фреймворке Qt5 с реализацией движения под произвольным углом с помощью матриц аффинных преобразований.

## Особенности реализации
* **Аффинные преобразования:** перемещение каждого сегмента змейки выполняется через умножение однородного вектора координат $[x, y, 1]^T$ на матрицу переноса $3 \times 3$.
* **Движение под произвольным углом:** координаты хранятся с плавающей точкой (`double`), а приращения вычисляются через тригонометрические функции угла направления.
* **Управление:**
  * `←` / `→` — плавный поворот вектора движения змейки.
  * `↑` / `↓` — разворот строго вверх или вниз.
  * `A` — ввод точного угла движения в градусах через диалоговое окно.
  * `Space` — перезапуск игры после столкновения.

## Сборка и запуск (Linux / CMake)
```bash
mkdir build && cd build
cmake ..
cmake --build .
./affine_snake
```
